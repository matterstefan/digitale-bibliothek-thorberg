# Digitale Bibliothek Thorberg

Interaktiver Forschungsprototyp zur Untersuchung historischer Standortsignaturen der erhaltenen Bände aus der Kartause Thorberg.

Die Website wird über GitHub Pages veröffentlicht. Die digitalen Bandaufnahmen und die fotografischen Medien bleiben miteinander verknüpft. Änderungsvorschläge werden vor einer Übernahme geprüft.

**Hinweis:** Die schematische Stapelansicht ist ein experimentelles Forschungsinstrument und keine gesicherte Rekonstruktion der historischen Aufstellung.
